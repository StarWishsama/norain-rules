# norain-rules

Personal proxy rule/override, design for Mihomo/Stash.

## Stash override

Stash override contains out-of-the-box experience for [Stash](https://stash.ws), contains config like DNS, Proxy Group, etc.

You can install from one of these source:

[GitHub](https://link.stash.ws/install-override/https://raw.githubusercontent.com/StarWishsama/norain-rules/refs/heads/main/override/stash.stoverride)

[jsDelivr fastly](https://link.stash.ws/install-override/https://fastly.jsdelivr.net/gh/StarWishsama/norain-rules@main/override/stash.stoverride)
